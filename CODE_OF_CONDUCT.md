# Code of Conduct

We want Clockwork Canary to be a practical, welcoming project. Treat other contributors with respect, critique ideas and evidence rather than people, and do not harass, threaten, discriminate against, or expose private information about anyone.

Maintainers may edit or remove abusive content and may temporarily or permanently restrict participation when behavior harms the community. Report conduct concerns privately through the repository owner's GitHub profile contact. Good-faith technical disagreement is welcome; personal attacks are not.
